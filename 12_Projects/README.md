# Projects

## 📌 Purpose

This folder contains complete, end-to-end project implementations that demonstrate practical application of embedded Linux, RTOS, and firmware development skills.

## 📚 Project Categories

- **IoT & Edge Computing** — Connected devices, gateway systems
- **Custom Linux Systems** — Production-ready embedded Linux
- **Firmware Systems** — MCU-based applications
- **Infrastructure** — OTA, monitoring, deployment

## 📁 Current Projects

### `iot-gateway/`
IoT edge gateway with sensor aggregation, cloud connectivity, and local processing.

### `yocto-custom-linux/`
Complete custom embedded Linux distribution using Yocto Project.

### `ota-firmware-system/`
Secure over-the-air firmware update system with rollback capability.

## 🎯 Project Standards

Each project follows consistent documentation:
- **README.md** — Project overview and quick start
- **docs/** — Detailed documentation
- **src/** — Source code
- **tests/** — Test suites
- **Makefile/CMakeLists.txt** — Build system
