# ESP32 Firmware

## 📌 Purpose

ESP32 firmware development using ESP-IDF (FreeRTOS-based).

## 📚 Topics Covered

- ESP-IDF project structure
- FreeRTOS on ESP32
- WiFi and BLE connectivity
- GPIO, I2C, SPI peripherals
- Non-volatile storage (NVS)
- OTA updates on ESP32
