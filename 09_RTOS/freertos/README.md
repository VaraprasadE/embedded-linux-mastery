# FreeRTOS

## 📌 Purpose

FreeRTOS development for LPC54628 and other ARM Cortex-M platforms.

## 📚 Topics Covered

- FreeRTOS kernel configuration
- Task creation and management
- Queues, semaphores, mutexes
- Software timers
- Memory management
- FreeRTOS+TCP, FreeRTOS+CLI
