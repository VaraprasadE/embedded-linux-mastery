# LPC54628 Development

## 📌 Purpose

Firmware development for NXP LPC54628 ARM Cortex-M4 microcontroller.

## 📚 Topics Covered

- MCUXpresso SDK setup
- Peripheral drivers (GPIO, UART, I2C, SPI)
- FreeRTOS integration
- USB device/host
- Ethernet connectivity
- Graphics with embedded GUI
