# Diagrams

## 📌 Purpose

This folder contains architecture diagrams, flowcharts, and visual documentation for embedded Linux concepts and projects.

## 📁 Diagram Categories

### Architecture Diagrams
- Linux boot sequence
- Kernel architecture
- Driver model
- Yocto build system

### Hardware Block Diagrams
- i.MX93 block diagram
- Peripheral connections
- Board layouts

### Flowcharts
- Boot flow
- Update process
- Driver initialization

### Sequence Diagrams
- I2C/SPI transactions
- Interrupt handling
- IPC mechanisms

## 🔧 Tools

- [draw.io / diagrams.net](https://app.diagrams.net/)
- [Mermaid](https://mermaid.js.org/) (in Markdown)
- [PlantUML](https://plantuml.com/)
- [Excalidraw](https://excalidraw.com/)
