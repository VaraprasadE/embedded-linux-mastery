# GPIO Drivers

## 📌 Purpose

GPIO (General Purpose Input/Output) driver development resources, examples, and documentation.

## 📚 Topics Covered

- GPIO subsystem architecture (gpiolib)
- GPIO descriptors API
- GPIO chip drivers
- GPIO consumer drivers
- GPIO interrupts (edge detection)
- LED subsystem integration
- GPIO-keys for button input
- Device tree GPIO bindings
