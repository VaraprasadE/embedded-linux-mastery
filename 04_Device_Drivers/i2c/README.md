# I2C Drivers

## 📌 Purpose

I2C (Inter-Integrated Circuit) device driver development resources, examples, and documentation.

## 📚 Topics Covered

- I2C subsystem architecture
- I2C adapter (controller) drivers
- I2C client (device) drivers
- SMBus protocol support
- I2C device tree bindings
- I2C debugging (i2c-tools)
- Multi-master and clock stretching
- I2C multiplexers
