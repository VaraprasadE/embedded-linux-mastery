# SPI Drivers

## 📌 Purpose

SPI (Serial Peripheral Interface) device driver development resources, examples, and documentation.

## 📚 Topics Covered

- SPI subsystem architecture
- SPI controller drivers
- SPI device (protocol) drivers
- SPI message and transfer handling
- SPI modes (CPOL, CPHA)
- Chip select handling
- DMA with SPI transfers
- SPI device tree bindings
